# AION-Project.eu

![](https://i.imgur.com/xnKTkk2.png)

The official website for the AION Project. It surfaces the project's game data and assets in the browser: a game database, player and game information, and a 3D engine page for exploring models and maps. It's also reachable from inside the game client.

## Features

- Server and game information in one place.
- Game database: items, npcs, quests, and more.
- Explore the game's models and maps directly in the browser via [IzFF](https://github.com/Iswenzz/IzFF).

## Building

_Pre-Requisites:_

1. [Node](https://nodejs.org/en/)
2. [Yarn](https://yarnpkg.com/)
